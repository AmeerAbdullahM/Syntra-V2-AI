# Syntra V2 Test Dataset Pack

This pack is designed to exercise the major Syntra V2 requirements:
multimodal fusion, evidence, alignment, conflict handling, uncertainty,
missing modalities, TXT input, general-knowledge fallback, queue isolation,
anonymous shared Q&A, and security/edge cases.

Start with expected_test_matrix/RUN_ORDER.md.

The files are intentionally synthetic and contain no preloaded application
data. Import/upload them through Syntra's normal user/admin workflows.

Note: synthetic MP3 files are media-path/queue fixtures, not realistic speech.
Use a real spoken recording for an ASR quality test.
